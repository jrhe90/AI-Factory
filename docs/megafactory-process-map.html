Review

What to check

How the flow behaves

  • Pack line sets the pace. End-of-Line Test is the slowest station at 50 min. With cycle variation, the 6% re-tests and transfer time, output settles near the 68-minute target.
  • Feeders run ahead. The module line needs about 43 min of work for the 4 trays a pack uses, so the rack warehouse fills and the module line waits. Frames build up on the paint rail the same way.
  • Module Install pulls 4 trays. It is starved if the rack warehouse holds fewer than 4.
  • Breakdowns. Any station can fault, about once every 37 hours of run time, for 50–110 min. The station stops and the stations around it are blocked or starved.
  • Exit is gated by the yard. The crane can only set a pack down when the pickup pad is free, and the pad clears only when a carrier pair has a free lot slot to go to.

Open questions

  1. Geometry Check, Cool & Inspect and Final QA have no reject path. Should a failed frame or pack go to a rework loop or an off-line repair bay?
  2. Re-tests always pass the second time. Do we want a scrap or teardown outcome for repeat failures?
  3. Cells arrive without limit. Should cell supply and the inbound dock be modelled as a constraint?
  4. There is no explicit frame buffer between Powder Coat and Chassis Load; the rail length is the buffer. Is a sized buffer needed for the analysis?
  5. Shifts run around the clock with no breaks or changeovers. Should planned downtime come out of the 30 GWh figure?
